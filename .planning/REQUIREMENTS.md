# Requirements: АвтоРитм

**Defined:** 2026-11-09  
**Core Value:** Владелец в любой момент понимает, что уже сделано с автомобилем, что требует внимания следующим и сколько это стоило.

## v1 Requirements

### Vehicle context

- [ ] **VEH-01**: Пользователь может указать марку, модель, год и текущий пробег своего автомобиля и увидеть сохранённое подтверждение.
- [ ] **VEH-02**: Пользователь понимает, что введённые данные сохранены только в текущем браузере и на устройстве.

### Maintenance plan

- [ ] **MNT-01**: Пользователь может создать работу с названием и сроком по дате, пробегу или обоим критериям.
- [ ] **MNT-02**: Пользователь видит для каждой запланированной работы понятный текстовый статус: срок наступил, осталось N километров или до какой даты выполнить.
- [ ] **MNT-03**: Пользователь не может сохранить план без названия работы и хотя бы одного срока.

### Service history and costs

- [ ] **HIS-01**: Пользователь может сохранить выполненную работу или расход с названием, суммой и датой.
- [ ] **HIS-02**: Пользователь видит записи истории в обратном хронологическом порядке и может удалить ошибочную запись.
- [ ] **HIS-03**: Пользователь видит пересчитанную общую сумму расходов после добавления или удаления записи.

### Experience and visual system

- [ ] **UX-01**: Пользователь проходит основной сценарий на мобильном экране с понятным следующим действием на каждом шаге.
- [ ] **UX-02**: Пользователь видит предсказуемые состояния интерфейса: пустой список, успех сохранения, ошибка ввода и наступивший срок.
- [ ] **UX-03**: Пользователь может различить обычный и срочный статус не только по цвету, а текст и интерактивные элементы остаются читаемыми.
- [ ] **UX-04**: Все ключевые экраны используют единые роли цветов, типографику, отступы и компоненты из `DESIGN.md`.

## v2 Requirements

### Trusted data and automation

- **DATA-01**: Пользователь может получить регламент работ для конкретной модификации из проверенного источника с датой данных.
- **DOCS-01**: Пользователь может загрузить чек или заказ-наряд, увидеть извлечённые данные и подтвердить запись до сохранения.
- **VALUE-01**: Пользователь может увидеть рыночный диапазон стоимости автомобиля с источником, регионом и датой оценки.
- **NOTF-01**: Пользователь может получить фоновое напоминание после явного разрешения уведомлений.

### Data continuity

- **SYNC-01**: Пользователь может войти в аккаунт и видеть свои данные на другом устройстве.
- **SYNC-02**: Пользователь может восстановить историю из резервной копии.

## Out of Scope

| Feature | Reason |
|---------|--------|
| VIN-отчёт, юридическая чистота и ДТП | Это другая продуктовая категория и нужны лицензированные данные. |
| Топливо, маршруты, доход и автопарк | Увеличивают когнитивную нагрузку, но не нужны для главного сценария одного владельца. |
| Автоматическое решение о ремонте | Продукт не заменяет руководство производителя или специалиста. |
| Игровая механика и «автоклуб» | Не поддерживает утилитарный, спокойный характер сервисной книжки. |
