# АвтоРитм

Локальный прототип мобильного веб-приложения для владельца автомобиля в России.

## Запуск

Откройте `index.html` в современном браузере. Установка зависимостей не нужна. Данные хранятся в локальном хранилище конкретного браузера и устройства. Очистка данных браузера может их удалить; синхронизации и резервного копирования пока нет.

## Уже работает

- Карточка автомобиля: марка, модель, год, пробег, модификация и регион.
- Ручной план работ с индикацией срока по пробегу и дате при открытии страницы.
- Ручной журнал работ и расходов, подсчёт суммы и удаление записей.

## Предстоит разработать

- Подключить проверенный источник регламентов ТО по модификации с подтверждением лицензии и покрытия.
- Загрузку и AI-распознавание чеков и заказ-нарядов с подтверждением пользователя.
- Рыночную оценку для регионов России по разрешённому источнику, с датой и диапазоном.
- Фоновые уведомления, аккаунты, серверное хранение и резервные копии.

Это прототип: AI, заводские регламенты, цены, загрузка чеков и фоновые уведомления не подключены. Сроки пользователь вводит сам и сверяет с руководством своего автомобиля.
